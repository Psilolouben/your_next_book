# your_next_book

A Go-based MCP server that turns your Goodreads library into personalized book recommendations via Claude (or any MCP-compatible client).

## How it works

1. **Sync** — `sync_goodreads_export` opens a Chrome window, walks you through the Goodreads export flow, and saves the CSV next to the binary.
2. **Fetch** — `fetch_books_list` reads that CSV and returns your full library (title, author, rating, shelves, year published) to the MCP client.
3. **Recommend** — the embedded prompt instructs the AI to score candidates and return the top 10 recommendations as JSON.

### Scoring system

| Criteria | Points |
|---|---|
| Strong thematic/genre overlap with 2+ favorites | +5 |
| Commonly co-read by readers with similar taste | +3 |
| Same author as a favorite | +1 |

Books already on your `read` shelf are excluded. The top 10 by score are returned in descending order.

## MCP tools

| Tool | Description |
|---|---|
| `sync_goodreads_export` | Opens a browser, handles Goodreads login, triggers a library export, and downloads the CSV — all in one step. |
| `fetch_books_list` | Reads the local CSV and returns your library to the MCP client for recommendation generation. |

## Project structure

```
proposal.go               — MCP server, CSV loading, tool registration and prompt
models/book.go            — Book struct
goodreads/export.go       — Browser automation for Goodreads CSV export (chromedp)
openai/openai.go          — Legacy OpenAI client (unused by the MCP server)
goodreads_library_export.csv — Your Goodreads library (generated by sync_goodreads_export)
```

## Setup

### Prerequisites

- Go 1.23+
- Google Chrome installed (used by the sync tool)

### Build

```bash
go build -o your_next_book .
```

### Configure in Claude Desktop

Add the server to your `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "booklist": {
      "command": "/path/to/your_next_book"
    }
  }
}
```

The binary must be built (not `go run`) so that CSV and `.env` paths resolve correctly relative to the binary location.

## Usage

### First run — sync your library

In Claude Desktop (or any MCP client), call:

```
sync_goodreads_export
```

A Chrome window will open. If you're not logged in, sign in to Goodreads. Once on the export page, click **Export Library**. The tool waits for the export to generate, downloads it, and saves it next to the binary.

### Get recommendations

After syncing, ask Claude something like:

> What books should I read next?

Claude will call `fetch_books_list` automatically, receive your library, apply the scoring prompt, and return the top 10 recommendations with scores and reasoning.

## Goodreads shelves

The tool understands three shelf statuses from your export:

| Shelf | Meaning |
|---|---|
| `read` | Already read — excluded from recommendations |
| `to-read` | On your reading list — may be recommended if highly scored |
| `looking-for` | Considering buying — treated like `to-read` |

## Notes

- The Chrome profile is persisted at `~/.goodreads_chrome_profile` so you only need to log in once.
- The MCP server communicates over stdin/stdout (stdio transport) — no network port is opened.
- The `openai/` package is a leftover from an earlier direct-API approach and is not used.
